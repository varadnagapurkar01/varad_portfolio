🔥 OPTION 2: WITH BACKEND DATABASE (5 MINUTES)

Step 1: Install Node.js
   → Go to: https://nodejs.org/
   → Download and install (use default settings)
   → Restart your computer

Step 2: Open Command Prompt in this folder
   → Press Shift + Right-click in this folder
   → Select "Open PowerShell window here"
   → Or "Open command window here"

Step 3: Install dependencies
   → Type: npm install
   → Press Enter
   → Wait for installation to complete

Step 4: Start the server
   → Type: npm start
   → Press Enter
   → You should see a success message

Step 5: Open your browser
   → Go to: http://localhost:3000/index.html
   → Now names are stored in database too!

Step 6: View admin dashboard
   → Go to: http://localhost:3000/admin-dashboard.html
   → See all visitors and stats

🐛 TROUBLESHOOTING:

Problem: Welcome screen shows every time
Solution: Check if localStorage is enabled in browser settings

Problem: "npm is not recognized"
Solution: Install Node.js from https://nodejs.org/

Problem: Backend not working
Solution: Make sure you ran "npm install" first

Problem: Animations are laggy
Solution: Close other browser tabs, or reduce particle count

More help in INSTALLATION-GUIDE.md
