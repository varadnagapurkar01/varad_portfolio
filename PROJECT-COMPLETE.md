## 🐛 Common Issues & Solutions

### Issue: Welcome screen shows every time
**Solution:** Check if localStorage is enabled in browser settings

### Issue: Backend won't start
**Solution:** Run `npm install` first, then `npm start`

### Issue: Animations are laggy
**Solution:** Reduce particle count in `js/welcome-popup.js`

**More help:** See `FAQ-TROUBLESHOOTING.md`

## 📊 Backend API Reference

If you set up the backend, you get these endpoints:

```
POST   /api/store-name
       Store visitor name
       Body: { name, timestamp, userAgent, referrer }

GET    /api/visitors
       Get all visitors (last 100)
       Returns: { success, count, visitors }

GET    /api/visitor-count
       Get total visitor count
       Returns: { success, count }

GET    /api/export-visitors
       Export all data to JSON
       Returns: { success, file, count }

GET    /api/health
       Check server status
       Returns: { status, timestamp }
```
